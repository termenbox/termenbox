# Guardrail: No cold read, no done

## Rule
A course part (Start, Master) **MUST NOT** be marked done in its plan or the roadmap until a person who has not used Termenbox has followed it from the README on a real phone, timed by a person, and the result (time per chapter, where they hesitated, wording that confused them) is saved as a fact.
Every stall that the cold read names **MUST** be fixed or filed as a roadmap step before the part is marked done. No telemetry is added to measure it.
