# R18 Owner-keyed server list and settings sync (C.4, 0068)
Status: pending
Score: V=8 T=5 R=6 S=13
Preds: R17
Lane: free
Area: cloud
Platform: both
Was: v2 C.4

## Do

Per-user encrypted object (list plus settings) read from the public domain with `no-cache`, written by a Worker with a conditional put; HKDF per-user secret issued with the device certificate; changes relayed to the owner's other connected devices through the servers' data channel; local outbox when a write fails; merge with localStorage on first login. Depends on the C.1 and C.6 verdicts for the storage layer.

## Done when

A server added in one browser appears in an open second browser within seconds, and on a closed one at its next open, with no Worker request for reads.

## Check

**Class:** implement

`cd packages/client && npx --yes pnpm@9 test`
