## Context

`ServerList.svelte` removal currently asks a native confirm and only forgets the server in this browser. The mode of each server arrives in `auth_ok.mode` (`container` or `host:<user>`). Container-mode uninstall must show one command: `docker rm -f termenbox && docker rmi ghcr.io/termenbox/termenbox && sudo rm -rf /opt/termenbox` (use the container name and data path the installer used).

## Do

1. Replace the confirm with a Remove server sheet: Forget in this browser (default), or Uninstall the server. Uninstall shows what will happen per the server's mode, the three opt-in checkboxes in host mode (off by default), a typed server name field, and requires a fresh login: if the certificate is older than 1 hour, show Sign in again first.
2. Send `uninstall`, show progress per stage, and on completion forget the server locally.
3. In container mode show the copy-paste command with a Copy button after stage 1.
4. Tests for the sheet states, the typed-name gate, the stale-certificate prompt and the command text; browser e2e uninstalls a test server and checks the config dir is empty.

## Done when

Unit tests pass; the e2e uninstall leaves an empty config dir and the app returns to the server list without the server.
