## Context

Root host sessions (decision 0058) must not rely on the device certificate alone.

## Do

1. WebAuthn registration at install (QR/command flow) and an assertion check every 12 h before a root session; verify on the server.
2. App: active sessions list, revoke device, end session.
3. Audit entries without session content.

## Done when

A root session cannot start without a fresh assertion; revoking a device ends its sessions; tests cover both.

## Check

**Class:** implement

`cargo test -p termenbox-server`

- **V=5**: root host sessions are an opt-in minority.
- **T=4**: nothing waits on it.
- **R=8**: a stolen device certificate alone opens a root shell.
- **S=8**: WebAuthn registration, assertion every 12 h, session list, revoke.
