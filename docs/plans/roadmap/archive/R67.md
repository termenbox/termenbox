## Why

The updater builds download URLs from `release_url` and the installer extracts only `X.Y.Z`, so a rolling alias release (which holds only a manifest) cannot work. Servers also have no per-server policy: every one auto-updates daily from one stream.

## Context

Per-server config, root-owned, written by the installer and updater: `[update] channel = stable|beta|nightly`, `mode = auto|notify|hold`, optional `maintenance_window = "03:00-04:00"` (local time). Defaults `stable` and `auto`; a nightly install defaults to `notify` (an unattended daily restart on a server that only wanted to try nightly is a surprise). Rules: a stable server never installs beta or nightly; a beta server installs stable (through the `channel-beta` alias) or beta/rc; a nightly server installs only nightly; a major bump needs `mode != auto` or owner confirmation. `notify` records the available version in status and `Request::UpdateNow` installs it; `hold` does nothing. Changing the channel later is a host-level act (re-run the installer or edit the config), not a web action.

## Do

1. `updater.rs`: take asset URLs from `manifest.binary(arch)`, `manifest.tmux(arch)` and `tmux_notices[*]`, never from `release_url`; apply the channel and trust-set checks of R66; honour mode, window and `UpdateNow`.
2. `packages/client/public/install.sh`: extract the full SemVer from the manifest; download from the manifest's binary URL; add `--channel stable|beta|nightly` and `--auto-update`; write the config; put `TERMENBOX_RELEASE_URL` in the systemd unit; keep `TERMENBOX_RELEASE_URL`, `TERMENBOX_IMAGE` and `TERMENBOX_RELEASE_KEYS` overrides.
3. Decisions to record: nightly is notify-only by default; the manifest, not the tag, names the assets. Guardrail: manifest URL resolution.

## Done when

Tests show: a stable server ignores a beta manifest; a beta server installs `0.2.0` from the alias; a nightly server sees only nightly; `notify` installs nothing until `UpdateNow`; the installer with `--channel beta` writes the beta config and unit and parses a prerelease version.
