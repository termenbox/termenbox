## Context

DECISION-0123. A server is one identity (key + pinned fingerprint) reached over candidate paths the client races. This step covers rungs 0 and 4 of the ladder (LAN, overlay as a candidate) and the client behaviour for all rungs; UPnP and self-diagnosis are R64, the tunnel is R33, hole punching waits for R63's numbers. Owner-sync of bundles lands with R18; until then the in-band refresh is the only sync.

## Do

1. Spike first, on a physical iPhone and an Android phone (GUARDRAIL-a-phone-check-names-its-platform): WebRTC from the hosted HTTPS client to an RFC1918 address, iOS local-network permission, `termenbox://` vs an `https://…/#/pair/…` link, and the same with the directory and internet blocked on the server (confirms FACT-0051). Record results as a fact; stop and revise 0123 if LAN fails on iOS.
2. `Candidate` and `Bundle` wire types in `termenbox-core` and `protocol.ts`: types `lan|wan4|wan6|overlay|tunnel`, `seq`, expiry. Canonical bytes are an explicit layout with shared test vectors; sign and verify with the directory key (GUARDRAIL-connection-hints-are-signed-and-never-identity).
3. Server: enumerate RFC1918 IPv4 (skip loopback, link-local, docker/br/veth/cni, tailscale/wg/tap/tun; at most 4; override `TERMENBOX_LAN_ADDRS`), persist `seq`, `--print-pairing` (link plus terminal QR) and `TERMENBOX_LAN_ONLY=1` (no directory publisher). Control endpoints stay on 127.0.0.1.
4. In-band bundle push after auth; the client stores it per server and keeps a stale bundle as a hint until a fresh one verifies.
5. Client pairing link `https://<client>/#/pair/<payload>`: verify, then preview with name and fingerprint (DECISION-0117), then connect.
6. Client path race: cached winner and LAN first, staggered 150-300 ms, first success wins, the rest are cancelled; remember the winner per server.
7. Seamless re-attach: on network change or a ~2 s heartbeat miss, re-race and re-attach; show the active path; all-failed screen lists each path tried, why it failed, and one fix; a CGNAT server with no relay says so and points to an overlay.
8. Tests per the guardrails (signature, tamper, stale `seq`, wrong fingerprint, corrupted-sig e2e, no private candidate in `Record`, zero directory calls in LAN-only) and an e2e for the race: first wins, first fails and second wins, all fail.
9. README section and the shortest possible line in the instruction file (cap 150).
