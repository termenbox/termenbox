## Context

DECISION-0124 is a draft; do not start before its open items are closed (EU consent advice, Honeycomb cap and terms, request budget). Its data decides whether hole punching and full ICE (0057 amendment) are worth building.

## Do

1. Close the open items in 0124; accept it and add the schema guardrail.
2. Event type with enum and bucket fields only, `sample_rate`, no ids; a schema test fails on any string field that is not an enum.
3. Client: per-session sampling, all failures kept, batched, silent on failure; first-run notice, settings toggle, `DO_NOT_TRACK` and Global Privacy Control honoured, off for the self-hosted client.
4. Pages Function: validate against the schema, drop the source IP, forward to Honeycomb; the sink URL is one config value.
5. A "view what is sent" screen and a public description of the schema.

## Done when

A sampled session produces one Honeycomb event with no address or id; the toggle and Do Not Track each stop all sending; the daily request count stays under 5% of the Pages budget in a load test.
