## Why

The per-agent view choice (Terminal or Agent view) ships with built-in ACP agents on by default. Two things need the owner, and the plan left several larger pieces out on purpose.

## Context

Decision 0137 records the choices and the rejected options; `docs/plans/acp-session-modes.md` has the plan, the prior art and the measurements. The e2e (`packages/client/e2e/acp-views.mjs`) uses a scripted fake agent on desktop Chromium: no real adapter and no real phone has run it.

## Do

Owner gates first:
- Decide whether `claude-agent-acp` with a user's own subscription login is allowed (Anthropic's Legal and compliance page, code.claude.com/docs/en/legal-and-compliance). If no, flip the `TERMENBOX_ACP` default to `off`.
- Manual check with a real claude or opencode adapter: create a session in each view, restart the container mid-turn, check the conversation returns and the interruption is stated, check an installed but logged-out adapter's error. Optionally measure idle and after-a-turn RSS to replace "a few hundred MB" in the guide.

Follow-ups, each built or dropped on its own:
- A detached ACP host that outlives the server; if wanted, reuse the agents' own servers (`opencode serve`, `goose serve`) and measure over our stdio transport first.
- Draining open turns on shutdown.
- A terminal projection of ACP sessions for SSH.
- A native TUI sharing one agent with the web view (opencode `serve`/`attach`; unverified).
- Probing login state before offering an agent.
- The full `agent-client-protocol` SDK, and ACP protocol v2 (`unstable_protocol_v2`), once agents ship v2.
- A "continue an earlier conversation" picker from `session/list` (unstable in the spec, not on every agent).
- A free-memory floor before starting a child.
- A Failed item for sessions left over the cap, and a viewer that picks up a session that finished restoring without reopening it.

## Done when

The owner has answered the terms question and the manual check passed on a real adapter, and each follow-up above is built or dropped with a reason.

## Check

**Class:** review

`grep -n "default_value = \"on\"" packages/server/src/main.rs` matches only if the owner kept the default; the manual check is the owner's.

## Notes

Not a gate for merging the view-choice PR except the terms question, which the PR states as unresolved.
