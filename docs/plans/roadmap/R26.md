## Context

Records are stored in D1 and written by `functions/api/directory/announce.ts`; there is no delete endpoint (only an idle expiry of 30 days in `_lib.ts`). The record is signed by the server's Ed25519 key (`directory.rs`).

## Do

1. Add `POST /api/directory/remove { server_id, ts, sig }` verifying a signature by the server key over `termenbox-remove-v1\n<server_id>\n<ts>` (ts within 5 minutes), deleting the record and its pending claim rows, with the same abuse limits as `announce`.
2. Add the signing and call to the server (`directory.rs`), invoked by the uninstall flow before the wipe.
3. Tests for a valid removal, a bad signature, a stale timestamp and a replay.

## Done when

Unit tests prove the four cases; a removed server id returns no record from `lookup`.
