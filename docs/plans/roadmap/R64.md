## Context

DECISION-0123 rung 1. Most home servers can be reached directly once the router forwards the UDP port; today the owner does it by hand, and a CGNAT server only finds out when a client fails.

## Do

1. At start, detect: global IPv6, the router's WAN address vs the externally seen one (CGNAT), UDP reachability of the bound port.
2. Try UPnP, NAT-PMP and PCP to open the port; renew the mapping; remove it on exit.
3. Print the topology (S1-S7 in 0123) and the next step in one short block; add the result to the candidate bundle (`wan6`, `wan4`).
4. Tests against a fake gateway for each protocol and for a refusal.

## Done when

Behind a router that supports UPnP the server becomes reachable from outside with no manual forward; behind CGNAT it prints that and names the options.
