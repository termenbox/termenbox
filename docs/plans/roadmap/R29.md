# R29 Migrate Docker host installs (N.7)

## Context

Existing owners may have run the old host mode: container `termenbox` started with `--pid=host --privileged`, `TERMENBOX_RUN=host`, config in `/opt/termenbox/home/.config/termenbox`. Decision 0075 retires it.

## Do

1. In the installer, when `host` or `host-user` is requested and such a container exists, offer the migration: stop the container, copy its config directory (server key, owner, revoked devices) to `/var/lib/termenbox` with the right ownership, install the native service (N.4) using the same UDP port, verify `/health`, then remove the container and image (journaled).
2. If anything fails, restart the old container.
3. Test in the N.4 CI environment with a fake old install.

## Done when

After migration the server id and owner are unchanged and the app reconnects without re-claiming; a forced failure leaves the old container running.

## Check

**Class:** implement

`sh -n packages/client/public/install.sh`

- **V=2**: only owners who ran the retired privileged host mode.
- **T=3**: every release carries the dead path until it is migrated.

- **S=5**: installer migration plus a CI test with a fake old install.
