# Contributing

Termenbox is developed in a private repository and this repository does not accept pull requests.

What helps most:

- **Bug reports**: [open an issue](https://github.com/termenbox/termenbox/issues/new/choose). Give the version
  (`termenbox-server --version`), your OS, what you did, what you expected and what happened. Do not paste tokens,
  keys or the output of commands that print them.
- **Ideas**: post them in [Discussions](https://github.com/termenbox/termenbox/discussions) under Ideas.
- **Security problems**: follow [SECURITY.md](SECURITY.md), never an issue.
