Why Termenbox

  • Built for the phone. Tabs per session, a key row for Esc, Ctrl and arrows, and a banner when an agent is waiting for you.
  • Survives bad networks. The session runs in tmux on your server. Lose signal or switch from Wi-Fi to cellular and it is still there; reconnecting re-attaches and repaints.
  • Direct and private. The browser talks to your server over an encrypted WebRTC data channel on one UDP port. No relay in the middle.
  • Works with your agents. Claude Code, Codex, OpenCode, or any program in a terminal.
  • Free and yours. MIT licensed. The server needs 512 MB of RAM and one vCPU.

Questions

Can I use Claude Code or Codex from my phone?

Yes. Install Termenbox on the machine where the agent runs, then use the app as the terminal: start the agent in a session, answer its questions from the banner, and come back later to the same session. Supported browsers: iOS Safari 16.4+, Chrome on Android 111+, and current Chrome, Firefox, Edge and Safari on desktop.

Is this like Mosh or tmux over SSH?

The persistence is tmux's: the server keeps the session and each connection attaches to it. Termenbox adds a browser client made for touch, a connection that re-races its paths after a network change, and notifications. It is not an SSH client.

Does my terminal traffic go through your servers?

No. It goes from your browser to your machine over an encrypted WebRTC data channel, and the browser pins the server's fingerprint. Only a signed record with the server's public key and address goes through the free directory.

Does it need a public IP or port forwarding?

On the same network as your phone, scan the QR the installer prints; on iPhone this depends on Safari's Local Network permission, which we have not finished testing. Away from home you need one reachable UDP port, or an overlay such as Tailscale. A server behind carrier-grade NAT can only be reached from its own network or over an overlay.

What does it cost?

Nothing beyond the machine you run it on. It is MIT licensed, with no subscription and no native app.
