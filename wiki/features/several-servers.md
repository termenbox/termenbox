# Several servers

Use more than one server from the same app. Back to the [README](../../README.md). Related: [How it connects](./connecting.md), [Workspaces and tabs](./workspaces.md).

## Add another server

Run the install command on the other machine, then tap **Add Server** or **Scan QR** on the Servers screen. On a server you already own, running the install command again prints a link that adds it to another browser.

## Name and remove

A server's menu lets you **Rename** it and **Remove** it. A rename is saved on the server and wins over the name it was installed with. **Remove** drops the server from your list; it does not uninstall anything, see [Install](../start/install.md) for that.

## Workspaces on each server

The sidebar lists every server with its workspaces. A server heading expands or collapses its workspaces, and each server has its own `+` that creates a workspace on that server.

## Notifications and addresses

A phone follows one server at a time for push notifications. A tunnel belongs to one server, and Settings, Tunnels lists every connected server with its state; see [How it connects](./connecting.md#tunnels-reaching-a-server-from-anywhere).
