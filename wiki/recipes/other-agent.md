# Start with an agent that is not a tile

Pick any agent for a new workspace, not only the three on show.

## Use when

The agent you want is not one of the three tiles in the new workspace sheet. Gemini is the example here.

## Steps

1. Start a new workspace. Tap **\+ New**.
2. Three agents are one tap; the rest are under More. Tap **More**.
3. Type a few letters to narrow the list.
4. Gemini is now the chosen agent.
5. Create it. Tap **Create**.

## Variations

- Choose Shell for a plain terminal with no agent.
- The full list of agents the sheet offers is on [Agents](../reference/agents.md).
- To pick the folder as well, see [Pick a folder from your server](./browse-folder.md).
