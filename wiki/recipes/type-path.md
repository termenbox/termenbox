# Type or paste a folder path

Go straight to a folder by its path.

## Use when

You know where the folder is and walking there would take many taps.

## Steps

1. Start a new workspace. Tap **\+ New**.
2. Know the path? Type it in the folder picker. Tap **Choose**.
3. Select this folder. Tap **Select this folder**.
4. Create it. Tap **Create**.

## Variations

- The path has to be inside the home directory of the user your workspaces run as.
- If you do not know the path, [pick the folder from your server](./browse-folder.md).
