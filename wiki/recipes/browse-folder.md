# Pick a folder from your server

Walk the folders of your server and choose where the workspace opens.

## Use when

The folder you want is not among the recent ones above the field.

## Steps

1. Start a new workspace. Tap **\+ New**.
2. Choose the folder from your server. Tap **Choose**.
3. Select this folder. Tap **Select this folder**.
4. Create it. Tap **Create**.

## Variations

- The picker only shows folders inside the home directory of the user your workspaces run as.
- If you already know the path, [type or paste it](./type-path.md) instead of walking there.
- A folder you used before is one tap away; see [Chapter 3](../course/03-first-workspace.md).
