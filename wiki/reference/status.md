# Status and the order of the workspace row

What a tab's status can be, and which one the workspace row shows. Back to the [README](../../README.md). Related: [Workspaces and tabs](../features/workspaces.md), [Agents](./agents.md).

## Roll-up order

1. **Needs you**
2. **Error**
3. **Done**
4. **Idle**
5. **Working**

**No status** is not ranked: the workspace row shows it only when no tab has a status.
