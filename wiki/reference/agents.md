# Agents and the tab limit

What you can start in a tab, and how many agent tabs a workspace holds. Back to the [README](../../README.md). Related: [Workspaces and tabs](../features/workspaces.md), [Status](./status.md).

## What a tab can run

Shell, Claude Code, Codex, Copilot, OpenCode, Gemini, Kilo, Aider, Goose, Amp, Qwen, Cursor.

## The limit

A workspace holds at most 6 agent tabs.
