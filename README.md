# Termenbox

Run Claude Code and Codex on your own server, from your phone. A self-hosted web terminal for AI coding agents:
workspaces live in tmux and survive dropped connections. No app required, no subscription.

## Install

On the Linux machine that will run your agents (a VPS or a home server; x86_64 or aarch64, with systemd):

```bash
curl -fsSL https://app.termenbox.dev/i | sh
```

Then open [app.termenbox.dev](https://app.termenbox.dev) on your phone or laptop, log in with GitHub, tap **Add Server**
and scan the QR the command printed. The command carries no secret and is safe to run again.
