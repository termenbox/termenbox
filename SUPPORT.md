# Getting support

1. Read the [wiki](https://github.com/termenbox/termenbox/wiki): installing and troubleshooting.
2. Ask in [Discussions](https://github.com/termenbox/termenbox/discussions) under Q&A.
3. If it is a bug, [open an issue](https://github.com/termenbox/termenbox/issues/new/choose) with your version and OS.

Security reports go through [SECURITY.md](SECURITY.md).
